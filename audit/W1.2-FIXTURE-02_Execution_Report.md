## 3. Detailed Results by Invariant Control

### Control 1: Legitimate Tenant-Admin Positive Control
- **Input:** Token signed with `ADMIN_SECRET` (`aud: 'admin'`, `tokenType: 'admin'`, `isAdmin: true`, `brand: 'realtutorialhub'`). Tenant DB returns `isBlocked: false`.
- **Observed:**
  - `requireAdminRouteAccess` verified the token cryptographically.
  - Step 0 queried `users.isBlocked` in the tenant DB.
  - Step 1 fast-pathed (`isAdmin === true`).
  - Access granted: returned verified payload with `userId === 'usr-admin-1'`.
- **Status:** **`PASSED`**.

### Control 2: Correctly Signed Learner Token at Admin Boundary
- **Input:** Token signed with `ACCESS_SECRET` (`aud: 'user'`, `tokenType: 'user'`, `isAdmin: false`).
- **Observed:**
  - Token presented to `requireAdminRouteAccess` via `admin_accessToken` cookie.
  - `verifyAdminAccessToken` attempted verification against `ADMIN_SECRET`.
  - Cryptographic verification failed fail-closed.
  - **Query Count Invariant:** Tenant database `users.isBlocked` query count was strictly **0**. Denial occurred at the token boundary *before* any database query.
- **Status:** **`PASSED`**.

### Control 3: Promoted Learner Account with In-Flight Learner Token
- **Setup:** Database fixture grants the learner account an `admin` role in PostgreSQL (`isBlocked: false`, `roles.name = 'admin'`).
- **Input:** Caller presents an in-flight learner token minted prior to promotion (`aud: 'user'`, `tokenType: 'user'`, `isAdmin: false`).
- **Observed:**
  - Token presented to `requireAdminRouteAccess`.
  - Access rejected fail-closed at the token boundary.
  - **Query Count Invariant:** The database `userRoles` fallback query in `_verifyAdmin` was **never queried** (`mockSelectRoles` called 0 times).
  - **Proven Security Invariant:** An in-flight learner token cannot gain administrative access merely because the user was promoted in the database; an explicit administrative login or token re-issuance is strictly required.
- **Status:** **`PASSED`**.

### Control 4: Missing Token
- **Input:** Request with no cookie and no Authorization header.
- **Observed:**
  - `verifyAdminOrInfraToken` threw `unauthorized('Unauthorized')`.
  - Zero database queries executed.
- **Status:** **`PASSED`**.

### Control 5: Invalid Signature / Forged Token
- **Input:** Token signed with an unrelated rogue secret.
- **Observed:**
  - `verifyAdminAccessToken` threw `JWSSignatureVerificationFailed`.
  - Zero database queries executed.
- **Status:** **`PASSED`**.

### Control 6: Incompatible Principal / Audience Mismatch
- **Input:** Valid SHC token (`aud: 'shc-admin'`) arriving at tenant admin route without `x-portal-identity: shc-admin`.
- **Observed:**
  - `verifyAdminOrInfraToken` derived `expectedAud = 'admin'` from default portal identity.
  - `verifyAdminAccessToken` threw `Error: Audience mismatch: expected admin, got shc-admin`.
  - Zero database queries executed.
- **Status:** **`PASSED`**.

### Control 7: Distinct Route Contract: Valid SHC Admin
- **Input:** `x-portal-identity: shc-admin`, valid SHC admin token (`aud: 'shc-admin'`, `brand: 'skillhubcore'`, `roles: ['admin']`, `isAdmin: true`).
- **Observed:**
  - Evaluated under the dedicated SHC branch in `requireAdminRouteAccess:64-75`.
  - Verified role in-memory (`roles.includes('admin')`).
  - Access granted: returned verified payload.
  - **Invariant:** Bypassed `_verifyAdmin`; zero queries to tenant PostgreSQL tables.
- **Status:** **`PASSED`**.

### Control 8: Distinct Route Contract: SHC Token with Insufficient Roles
- **Input:** `x-portal-identity: shc-admin`, SHC token with `roles: ['viewer']` (missing admin, super_admin, infrastructure).
- **Observed:**
  - Evaluated under SHC branch in `requireAdminRouteAccess`.
  - Threw `forbidden('SkillHubCore admin access only')`.
  - Zero tenant DB queries.
- **Status:** **`PASSED`**.

### Control 9: Distinct Route Contract: Valid Infrastructure Token
- **Input:** `x-portal-identity: infrastructure`, valid infra token (`aud: 'infra'`, `roles: ['infrastructure']`, `isAdmin: true`).
- **Observed:**
  - Evaluated under infra branch in `requireAdminRouteAccess:76`.
  - Bypassed `_verifyAdmin`; access granted.
  - Zero tenant DB queries.
- **Status:** **`PASSED`**.

### Control 10: Blocked Tenant Admin in Database
- **Input:** Valid admin token presenting, but tenant DB record has `users.isBlocked === true`.
- **Observed:**

  - `_verifyAdmin` queried `isBlocked` (Step 0) and observed `true`.

- **Status:** **`PASSED`**.
