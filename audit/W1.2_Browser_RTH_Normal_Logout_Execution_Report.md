     - Hashes current session token.
     - Calls `brandTokenRepo.revokeToken(tokenHash)` for the active token only.
     - Logs audit action `logout_success` with metadata `{ deviceSpecific: true }`.
   - **Verification**: The route performs **device-specific single-session logout only**. It does **NOT** call `DELETE /api/auth/sessions`, `logoutAllDevices`, or global token revocation.

