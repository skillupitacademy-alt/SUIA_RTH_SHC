## 1. Executive Summary & Test Intent

This report documents the self-contained execution of **`W1.2-FIXTURE-01`**.

The objective of this suite is to exercise the actual `LoginService.login` and `PasswordService` (bcryptjs) authentication paths under synthetic, colliding-identity conditions across two independent tenants:
- **Tenant A:** SkillUp IT Academy (`brand: 'skillup'`)
- **Tenant B:** RealTutorialHub (`brand: 'realtutorialhub'`)

### Seeded Synthetic Identity Invariants:
- **Shared Synthetic Email:** `learner@example.test` (identical on both tenants).
- **Colliding Local User ID:** `'100'` (identical string ID on both tenants).
- **Distinct Tenant Passwords:**
  - SUIA: `Password-SUIA-Secret!1` (bcrypt salt rounds 10).
  - RTH: `Password-RTH-Secret!2` (bcrypt salt rounds 10).
- **Distinct Profile Markers:**
  - SUIA: `SUIA Learner Profile` (Education: `College`, Status: `Student`).
  - RTH: `RTH Learner Profile` (Education: `Graduate`, Status: `Developer`).
- **Prepopulated Shadow User IDs:**
  - SUIA: `shadow-suia-100`
  - RTH: `shadow-rth-100`

## 2. Self-Containment & Containment Controls

In accordance with Sol's review requirements:
1. **Explicit Disposable Cryptographic Keys:**
   - The test constructs `TokenService` using explicit 32-byte disposable keys:
     - `disposableAccessSecret` (`Uint8Array`)
     - `disposableRefreshSecret` (`Uint8Array`)
     - `disposableAdminSecret` (`Uint8Array`)
   - The test does NOT depend on ambient `process.env.JWT_SECRET` or static configuration files.
2. **Fail-Fast Outbound Network Guard:**
   - In `beforeEach`, `globalThis.fetch` is replaced with a stub that throws immediately:
     `throw new Error('Outbound network transport blocked in isolated fixture')`.
   - In `afterEach`, the original `globalThis.fetch` is cleanly restored.
3. **Identity Bridge Fast-Path Verification:**
   - In `LoginService.login:178`, `ensureShadowUserId` inspects `user.shadowUserId`.
   - Because both seeded accounts have valid, non-empty shadow IDs (`'shadow-suia-100'` and `'shadow-rth-100'`), `ensureShadowUserId` executes the fast path: `return user.shadowUserId;`.
   - The suite spies on `UserIdentityBridgeService.prototype.syncUser` and asserts `expect(mockIdentityBridgeSync).toHaveBeenCalledTimes(0)`.
   - **Correction from initial report:** The fallback/testEnv catch branch did NOT execute; the fast path returned the pre-existing shadow ID directly without external calls.
4. **Adapter Scope & Physical Database Boundaries:**
   - The in-memory tenant stores (`InMemTenantStore`) implement repository adapter interfaces (`findWithDetails`, `updateLastActive`, `createRefreshToken`).
   - **Untested Layers:** This fixture does **not** execute actual `UserRepository` Drizzle ORM SQL queries or physical PostgreSQL schema/connection isolation.
   - **Non-Closure Notice:** Passing this isolated backend fixture proves tenant partitioning in `LoginService` memory adapters; it **never claims browser AQ-08 closure**.
