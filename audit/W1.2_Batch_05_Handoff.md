## 6. Pending Owner Decisions and Missing Prerequisites

### A. Decisions Awaiting Owner Guidance
1. **SHC GUI Compatibility Strategy (from GUARD-02):**
   - **Option A (Preserve Current Architecture):** Acknowledge that SHC admin sessions use 8-hour stateless JWTs without refresh cookie rotation. Retain current client refresh as a graceful no-op on SHC.
   - **Option B (Implement True SHC Refresh):** Add `refresh_token_skillhubcore` cookie issuance and persistence in `skillhubcore_db.refresh_tokens`.
   - **Option C (Decommission SHC Refresh Helpers):** Remove the unmounted `services/skillhubcore-service` refresh helpers to eliminate dead code.
2. **Legacy Logout-All Route Resolution (from SESS-02):**
   - **Option 1 (Decommission):** Remove `POST /api/auth/logout-all` in Wave 2 maintenance since frontends already use `DELETE /api/auth/sessions`.
   - **Option 2 (Delegate):** Wire `POST /api/auth/logout-all` to `GlobalLogoutService.logoutAllDevices` for backward compatibility.

### B. Missing Environmental Prerequisites for Browser Smoke Runs (from BROWSER-01)

2. **Local Test Database:** Docker test PostgreSQL container on port 55432 (`docker compose -f docker-compose.test-db.yml up -d`) is offline.
3. **Synthetic Test Accounts:** Environment credentials (`TEST_SUIA_LEARNER_*`, `TEST_RTH_LEARNER_*`, `TEST_SHC_ADMIN_*`, `TEST_BLOCKED_LEARNER_*`) must be provisioned before live authenticated runs.
4. **App Binding:** Running Next.js servers must be started against local test databases rather than remote Neon databases.
