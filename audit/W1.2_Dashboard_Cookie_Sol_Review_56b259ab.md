## R1 - Learner denial assertions accept navigation failures as success

AQ-01/AQ-02 accept any exception from page.goto as directNavFailed=true, then treat it
as protected-access denial. A timeout or network failure therefore also passes. A
Location merely containing /login does not establish the approved origin or route.
The tests bypass guardedApiFetch with page.request.get, then intentionally count the
browser origin guard blocking a foreign redirect as a successful journey.

Independent credential-free GETs to each local /dashboard, redirect:manual, observed:

| App | Status | Same-origin Location | Production login host | Login path |
| --- | --- | --- | --- | --- |
| SUIA :3009 | 307 | false | true | true |
| RTH :3003 | 307 | false | true | true |

No production redirect was followed. These responses support a real local login-routing
defect and an absence of direct HTTP 200 dashboard success for those requests. They do
not prove an exploitable authorization bypass or justify accepting the intended local
browser journey. Fix the product separately under PROXY-01, then require exact guarded
same-origin login behavior without catch-all success. Do not repeat learner live logins
merely to reproduce a known blocked redirect.

The onboarding skip also occurs after the exact /dashboard assertion, making it
unreachable if that assertion fails. Classify an observed onboarding outcome before
asserting a dashboard pass, without suppressing other errors.

## R3 - Cookie qualification is narrower than its reported matrix

SHC checks omit Secure and Domain, although the report marks development Secure=false
and host-only scope PASS. Learner csrfToken checks omit Domain/Secure/SameSite. Learner
domain regexes accept additional subdomains (for example x.skillup.localhost), not just
the canonical expected domain. matching.length > 0 permits duplicate same-name cookies
and does not qualify duplicate-scope ambiguity. Identical policy-verifier code is
copied into three specs instead of one small task-local typed helper.

Derive exact required metadata from actual issuance and rewriting. SHC's current source
sets Secure by NODE_ENV, SameSite=Lax, Path=/ and host-only issuance. Do not treat these
source facts as independently asserted runtime results until the assertions exist.
Preserve boolean-only diagnostics and add offline synthetic tests for rejected wrong
domain, wrong flags and duplicate scope. Do not modify accepted safety helpers or
serialize real cookies. Updated assertions require fresh attributable execution; they
cannot inherit the prior passes.
