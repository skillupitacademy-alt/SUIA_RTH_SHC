## Single remaining blocker: an arbitrary path is still treated as owned

playwright.auth-qualification.config.ts accepts AUTH_QUALIFICATION_OUTPUT_DIR via
path.resolve with no bounded-root or ownership validation. Default .run-artifacts is
also a shared fixed directory, not a unique run directory. Reporter constructor accepts
the same unrestricted path. onEnd recursively deletes this.ownedOutputDir after only
checking that it exists and is not exactly process.cwd(). Thus a workspace parent,
foreign report directory or arbitrary existing temp directory can be deleted.
Playwright may also clean configured outputDir before the reporter runs, so validation
must precede returning config, not only guard reporter cleanup.

isSafelyContainedInOwnedDir is lexical and checks only lstat of the final target. A
regular file beneath a symlink/junction ancestor can pass containment while resolving
outside the owned root. Its current comment and handoff overstate protection.

Independent no-deletion probe used actual reporter with an unrelated dedicated temp
directory and fake canary. fs.rmSync was intercepted to record the target and throw
before deleting anything. onEnd attempted recursive removal of the supplied unowned
root: TRUE; canary preserved: TRUE; exit 0. Only probe-created canary/directory were
then removed with exact nonrecursive operations. No existing reports were deleted.

The submitted foreign-canary test proves sibling containment for a caller-declared
root; it does not prove that root is genuinely run-owned or that ancestors are safe.
