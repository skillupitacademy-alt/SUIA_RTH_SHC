### 2. Auth Pattern Coverage - FIXED

**Finding**: `document.cookie` read, `localStorage.setItem('accessToken')`, direct `jose.jwtVerify` incorrectly pass.

**Root Cause**: Security rules did not scan for these patterns.

**Correction**: Added three new scan rules with fail-closed detection.

**Implementation**:

**Rule 1: document.cookie Detection**
```javascript
const cookieRegex = /document\.cookie/;
if (cookieRegex.test(content)) {
  violations.push({
    file: relPath,
    rule: 'no-document-cookie',
    message: 'Direct document.cookie access detected'
  });
}
```

**Rule 2: localStorage Auth Persistence**
```javascript
const localStorageAuthRegex = /localStorage\.(get|set)Item\s*\(\s*['"](?:accessToken|refreshToken|token|jwt|session|auth)/i;
if (localStorageAuthRegex.test(content)) {
  violations.push({
    file: relPath,
    rule: 'no-localstorage-auth',
    message: 'localStorage used for auth token persistence'
  });
}
```

**Rule 3: Direct JWT Library Import** (AST-based)
```javascript
traverse(ast, {
  ImportDeclaration(path) {
    const source = path.node.source.value;
    if ((source === 'jose' || source === 'jsonwebtoken') && 
        !relPath.startsWith('packages/auth/')) {
      violations.push({
        file: relPath,
        rule: 'no-direct-jwt',
        message: `Direct JWT library import outside @quiz/auth`
      });
    }
  }
});
```

**Evidence**: Test fixtures verify detection:
```
✓ document.cookie read detected in api route
✓ localStorage.setItem('accessToken') detected
✓ Direct jose import detected outside packages/auth
```

### 3. Orchestrator Validation - FIXED

**Finding**: `--stage=toString`, `--stage=constructor`, `--stage=__proto__` exit 0 (prototype pollution vulnerability).

**Root Cause**: No input validation on stage parameter.

**Correction**: Explicit allowlist validation with unknown argument rejection.

**Implementation**:
```javascript
// scripts/quality-gate-skillhubcore.mjs
const VALID_STAGES = ['guards', 'security', 'lint', 'typecheck', 'test', 'build'];

function validateStageArg(stage) {
  if (!VALID_STAGES.includes(stage)) {
    console.error(`❌ Invalid stage: "${stage}"`);
    console.error(`Valid stages: ${VALID_STAGES.join(', ')}`);
    process.exit(1);
  }
}

// Unknown argument rejection
const knownArgs = ['--stage', '--skip-checks'];
for (const arg of process.argv.slice(2)) {
  if (arg.startsWith('--')) {
    const flag = arg.split('=')[0];
    if (!knownArgs.includes(flag)) {
      console.error(`❌ Unknown argument: ${flag}`);
      process.exit(1);
    }
  }
}
```

**Evidence**: 8 orchestrator tests verify protection:
```
✓ --stage=toString rejected (exit 1)
✓ --stage=constructor rejected (exit 1)
✓ --stage=__proto__ rejected (exit 1)
✓ --unknown-flag rejected (exit 1)
✓ Valid stages pass (guards/security/lint/typecheck/test/build)
```

**Root Cause**: Tests wrote violations directly into `apps/skillhubcore/app/routes/`.

**Correction**: All tests now use disposable fixtures in temporary directories.

**Evidence**: All 21 tests (13 checker + 8 orchestrator) use disposable fixtures. No application files modified during testing.
