## Scoped source conclusions

The new policy is limited to generic user/admin refresh for skillup and
realtutorialhub. Signature, expiration and audience verification precede state
writes. The scoped path requires signed/stored subject agreement, valid canonical
brand agreement (with accepted absent-brand compatibility), and consistent present
principal-class claims. Null/unsupported/conflicting claims fail closed. The
original routing resolver remains; the refresh route uses a separate strict helper.

UserRepository is an optional fourth dependency, lazily resolved and bound only
for the scoped tenant path. Strict core/role lookup bypasses profiles, propagates
query failures, and distinguishes missing user from successful empty roles.
Blocked/deleted/missing/query-error/demoted denials precede lastUsedAt updates,
consumption and successor insertion. Audit attempts are separate permitted writes.
The existing lastUsedAt write remains after eligibility and before token signing/
CAS; an operational failure or CAS race loss after that point is not guaranteed
to roll back that earlier timestamp. The zero-write proof concerns pre-rotation
authority/eligibility denial, not every possible late failure. Consume/replacement
atomicity and the broader failure policy remain separately qualified.

Fresh learner claims omit administrative roles and keep user audience/type/key
selection and isAdmin=false. Tenant-admin refresh needs current administrative
eligibility; demotion denies without falsely logging a revocation. Generic infra,
default-DB and SHC paths do not receive the new tenant policy or user dependency.
Their existing claim/audience derivation is retained. The original CAS transaction,
legacy no-jti verifier compatibility and existing TTLs are preserved.
