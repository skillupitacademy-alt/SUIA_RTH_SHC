## 3. Initial Run Defect & Root Cause (`8cf421c5`)

In commit `8cf421c5`, AQ-05-NORMAL executed against `http://skillup.localhost:3009` and failed at cookie clearance:
- In `apps/skillup-web/src/app/api/auth/logout/route.ts`, the BFF stripped the backend's `Set-Cookie` headers and called `response.cookies.set(...)` without `domain`.
- Because login sets domain cookies (`Domain=.skillup.localhost`), omitting `domain` resulted in a host-only clear that did not remove the domain cookie in Chromium.
- The defect was independently reproduced by Sol in `audit/W1.2_Browser_SUIA_Logout_Sol_Review_8cf421c5.md` via an offline Chromium matrix and assigned as `W1.2-LOGOUT-01`.

## 4. Remediation Implementation (`W1.2-LOGOUT-01`)

In accordance with [`audit/W1.2_Gemini_SUIA_Logout_Cookie_Correction_Task.md`](file:///E:/onlinewebsites/quiz-platform/audit/W1.2_Gemini_SUIA_Logout_Cookie_Correction_Task.md):

   Updated [`apps/skillup-web/src/app/api/auth/logout/route.ts`](file:///E:/onlinewebsites/quiz-platform/apps/skillup-web/src/app/api/auth/logout/route.ts) to delegate directly to `proxyAuthRequest`:
   ```typescript
   export async function POST(request: NextRequest) {
     return proxyAuthRequest(request, {
       fallbackApiBase: FALLBACK_API_BASE_SKILLUP,
       authPath: 'logout',
     });
   }
   ```
   This preserves:
   - Upstream token revocation and response status.
   - All response headers without modification.
   - Canonical `rewriteSetCookie` processing, ensuring every cookie returned by the upstream endpoint is rewritten with matching `Domain` and `Path`.
