## Verification Commands

### 1. CSV Structure Validation

```powershell
# Parse and count
$csv = Import-Csv "audit/Audit_Finding_Root_Cause_Crosswalk.csv"
Write-Host "Total rows: $($csv.Count)"  # Expected: 91

# Status check
$csv | Group-Object status | Format-Table Count, Name -AutoSize  # Expected: 91 PLANNED

# Root cause distribution
$csv | Group-Object primary_root_cause | Sort-Object Name | Format-Table Count, Name -AutoSize
```

### 2. Provenance Key Uniqueness

```powershell
$csv = Import-Csv "audit/Audit_Finding_Root_Cause_Crosswalk.csv"
$grouped = $csv | Group-Object source_document,source_section_or_line,original_finding_id
$duplicates = $grouped | Where-Object { $_.Count -gt 1 }

if ($duplicates) {
    Write-Host "❌ Duplicate provenance keys found"
    $duplicates | Format-Table Count, Name -AutoSize
} else {
    Write-Host "✅ All provenance keys unique"
}
```

### 3. Broad Locator Detection

```powershell
$csv = Import-Csv "audit/Audit_Finding_Root_Cause_Crosswalk.csv"
$broad = $csv | Where-Object {
    $_.'source_section_or_line' -match '^Section: ' -and
    $_.'source_section_or_line' -notmatch 'Line \d+'
}

if ($broad) {
    Write-Host "❌ Broad locators found"
    $broad | Format-Table original_finding_id, source_section_or_line -AutoSize
} else {
    Write-Host "✅ All entries have exact line numbers"
}
```
