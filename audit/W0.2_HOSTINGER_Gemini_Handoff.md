## Background Context

### The Problem
Deployment script `scripts/deploy-smart.ps1` had `-SkipChecks` flag that bypassed quality gates, allowing unchecked source to reach production. W0.2 ticket closed this gap for repository-level deployments. **W0.2-HOSTINGER** extends enforcement to Hostinger VPS deployments via Docker images.

### Sol's Design Decision
File: `audit/W0.2_HOSTINGER_Sol_Design_Decision.md`

**Core Requirements**:
1. Mandatory SkillHubCore quality gate executes BEFORE Docker build
2. Gate CANNOT be bypassed by `-SkipChecks` flag
3. Full 40-character commit SHA captured in evidence
4. Fail closed on git errors, dirty source, or invalid evidence
5. Source verified at 3 checkpoints: before gate, after gate, after build
6. Previous evidence invalidated before new gate execution
7. Evidence is transient operational receipt (not tamper-proof SLSA)
8. Builder validates evidence before creating Docker images

### Implementation Strategy
- **Step 4.5** added to `deploy-smart.ps1` (after TypeScript, before Docker)
- New helper: `scripts/enforce-shc-quality-gate.ps1`
- Modified builder: `infra/hostinger/scripts/build-save-images.ps1`
- Evidence stored: `infra/hostinger/dist/evidence/shc-gate-<imageTag>.json`
- 8/8 enforcement tests passing (gitignored test file)

## Evidence Schema Reference

**Location**: `infra/hostinger/dist/evidence/shc-gate-<imageTag>.json`

**Expected Structure**:
```json
{
  "version": "1.0",
  "service": "skillhubcore-admin",
  "sourceCommit": "<40-char SHA>",
  "imageTag": "<12-char tag>",
  "invocationId": "<UUID>",
  "gate": {
    "command": "pnpm",
    "profile": "quality:skillhubcore"
  },
  "timing": {
    "startUtc": "<ISO 8601 timestamp>",
    "completionUtc": "<ISO 8601 timestamp>"
  },
  "status": "PASS",
  "exitCode": 0
}
```

**Field Validation**:
- `version`: Must be "1.0"
- `sourceCommit`: Must be exactly 40 characters (full SHA)
- `imageTag`: Must match deployment imageTag
- `invocationId`: Must match builder parameter
- `status`: Must be "PASS" for valid evidence
- `exitCode`: Must be 0 for valid evidence
