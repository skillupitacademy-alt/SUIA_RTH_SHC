## Design: Mandatory SHC Quality Gate

### Invariants (from Sol)

1. ✅ Run `pnpm quality:skillhubcore` before SHC build/upload
2. ✅ `-SkipChecks` cannot bypass this gate
3. ✅ No new bypass or emergency override
4. ✅ Any applicable failure aborts before build/upload/restart
5. ✅ Resolve explicit, default and auto-detected services consistently
6. ✅ Mixed-service results identify SHC coverage only
7. ✅ Tested source must match build input
8. ✅ HEAD equality alone cannot qualify dirty source
9. ✅ Missing, stale or mismatched required evidence fails closed
10. ✅ Do not expose environment values or secrets in evidence

### Proposed Solution

#### 1. Add Pre-Build Quality Gate Invocation

**Location**: `deploy-smart.ps1` between Step 4 (TypeScript) and Step 5 (Build)

**Logic**:
```powershell
# Step 4.5: Run mandatory quality gates for applicable services
Write-Info "Step 4.5/8: Running mandatory quality gates..."

$qualityGateServices = @{
    "skillhubcore-admin" = @{
        gate = "pnpm quality:skillhubcore"
        workdir = "apps/skillhubcore-admin"
    }
    # Future: Add other services as they implement quality gates
}

$hasQualityFailures = $false

foreach ($service in $servicesToDeploy) {
    if ($qualityGateServices.ContainsKey($service)) {
        $gateInfo = $qualityGateServices[$service]
        
        Write-Host "  -> Running quality gate for $service..." -ForegroundColor Gray
        Write-Host "     Command: $($gateInfo.gate)" -ForegroundColor DarkGray
        
        Push-Location $gateInfo.workdir
        try {
            # Run quality gate (cannot be skipped)
            Invoke-Expression $gateInfo.gate
            
            if ($LASTEXITCODE -ne 0) {
                Write-Err "Quality gate failed for $service (exit code: $LASTEXITCODE)"
                $hasQualityFailures = $true
            } else {
                Write-Success "Quality gate passed for $service"
            }
        } finally {
            Pop-Location
        }
    }
}

if ($hasQualityFailures) {
    Write-Err "One or more mandatory quality gates failed"
    Write-Host ""
    Write-Host "Quality gates cannot be bypassed with -SkipChecks." -ForegroundColor Yellow
    Write-Host "Fix the reported issues and re-run deployment." -ForegroundColor Yellow
    Write-Host ""
    exit 1
}

if ($qualityGateServices.Keys | Where-Object { $servicesToDeploy -contains $_ }) {
    Write-Success "All mandatory quality gates passed"
}
```

**Key Characteristics**:
- Runs AFTER Steps 1-4 (but before build)
- Runs for `skillhubcore-admin` when present in `$servicesToDeploy`
- NOT affected by `-SkipChecks` flag
- Failure aborts entire deployment (exit 1)
- No bypass mechanism
- No emergency override

#### 2. Provenance Evidence

**Capture at Quality Gate Success**:
```powershell
# After quality gate passes for a service
$evidence = @{
    service = $service
    commit = $tag
    timestamp = (Get-Date -Format "yyyy-MM-ddTHH:mm:ssZ")
    gate = $gateInfo.gate
    status = "PASS"
    exitCode = 0
}

$evidencePath = ".\infra\hostinger\dist\evidence\quality-gate-$service-$tag.json"
New-Item -ItemType Directory -Force -Path (Split-Path $evidencePath) | Out-Null
$evidence | ConvertTo-Json | Set-Content -Encoding UTF8 $evidencePath
```

**Verify at Build Start**:
```powershell
# In build-save-images.ps1, before Docker build
foreach ($service in $Services) {
    if ($service -eq "skillhubcore-admin") {
        $expectedEvidence = "..\..\dist\evidence\quality-gate-$service-$ImageTag.json"
        
        if (-not (Test-Path $expectedEvidence)) {
            Write-Error "Missing quality gate evidence for $service (commit $ImageTag)"
            Write-Error "Evidence file not found: $expectedEvidence"
            exit 1
        }
        
        $evidence = Get-Content $expectedEvidence | ConvertFrom-Json
        
        # Verify evidence matches current build
        if ($evidence.commit -ne $ImageTag) {
            Write-Error "Evidence commit mismatch for $service"
            Write-Error "  Evidence commit: $($evidence.commit)"
            Write-Error "  Build commit: $ImageTag"
            exit 1
        }
        
        if ($evidence.status -ne "PASS") {
            Write-Error "Quality gate did not pass for $service"
            exit 1
        }
        
        Write-Host "  -> Quality gate evidence verified for $service" -ForegroundColor Gray
    }
}
```

**Evidence Properties**:
- `service`: Service name (e.g., "skillhubcore-admin")
- `commit`: Git commit SHA (12-char short hash)
- `timestamp`: ISO 8601 timestamp
- `gate`: Command executed (e.g., "pnpm quality:skillhubcore")
- `status`: "PASS" or "FAIL"
- `exitCode`: Process exit code
- **No environment variables or secrets**

#### 3. Source Drift Detection

**Check Working Tree State**:
```powershell
# After git tag acquisition, before quality gate
$gitStatus = git status --porcelain

if ($gitStatus) {
    Write-Err "Working tree has uncommitted changes"
    Write-Host ""
    git status --short
    Write-Host ""
    Write-Err "Quality gate requires clean working tree for provenance"
    Write-Host "Commit or stash changes before deploying." -ForegroundColor Yellow
    exit 1
}
```

**Verify HEAD Matches Evidence**:
```powershell
# Evidence verification includes commit equality check (shown above)
if ($evidence.commit -ne $ImageTag) {
    # Fails closed - cannot deploy with mismatched evidence
    exit 1
}
```

#### 4. Mixed-Service Handling

**Current**: `$servicesToDeploy` can contain multiple services

**Enhancement**: Quality gate output identifies which services were checked

```powershell
Write-Host ""
Write-Host "Quality Gate Summary:" -ForegroundColor Cyan
Write-Host "  Services with mandatory gates:" -ForegroundColor Gray

$servicesWithGates = $servicesToDeploy | Where-Object { $qualityGateServices.ContainsKey($_) }
$servicesWithoutGates = $servicesToDeploy | Where-Object { -not $qualityGateServices.ContainsKey($_) }

if ($servicesWithGates) {
    $servicesWithGates | ForEach-Object {
        Write-Host "    ✓ $_" -ForegroundColor Green
    }
}

if ($servicesWithoutGates) {
    Write-Host "  Services without mandatory gates:" -ForegroundColor Gray
    $servicesWithoutGates | ForEach-Object {
        Write-Host "    - $_ (no gate required)" -ForegroundColor DarkGray
    }
}

Write-Host ""
```

## Testing Strategy

### Test Cases (Disposable/Mock-Based)

1. **SHC deployment without -SkipChecks**
   - Quality gate runs
   - Deployment proceeds if gate passes

2. **SHC deployment with -SkipChecks**
   - Quality gate STILL runs (not bypassed)
   - Deployment proceeds if gate passes

3. **Mixed services containing SHC**
   - SHC quality gate runs
   - Other services proceed without gate
   - Output identifies coverage

4. **Non-SHC selection without false SHC qualification**
   - No SHC in `$servicesToDeploy`
   - No quality gate invocation
   - Deployment proceeds normally

5. **Gate failure prevents build/upload**
   - Mock gate returns exit 1
   - Deployment aborts before build
   - No Docker images created
   - No artifacts uploaded

6. **Dirty source detection**
   - Uncommitted changes present
   - Deployment aborts before gate
   - Error message instructs to commit/stash

7. **Stale evidence detection**
   - Evidence file has different commit SHA
   - Build aborts with mismatch error

8. **Missing evidence detection**
   - Evidence file doesn't exist
   - Build aborts with missing file error

9. **Manifest/source/artifact association**
   - Evidence commit matches image tag
   - Manifest includes evidence reference

10. **Correct exit propagation**
    - Gate exit 1 → deploy-smart.ps1 exit 1
    - Gate exit 0 → continues to build

### Test Implementation

Use PowerShell Pester or stub scripts:
- Mock `git` commands for controlled scenarios
- Mock `pnpm quality:skillhubcore` with exit codes
- Mock file system operations for evidence
- Verify command execution order
- Verify exit codes
- No real Docker builds
- No SSH/SCP to production

## Remaining Risks

### Unverified

1. **VPS Runtime Behavior**: Deployment scripts on VPS not tested
2. **Network Reliability**: SSH/SCP failure handling
3. **Docker Compose Load**: `deploy-load-production.sh` behavior
4. **Service Health**: Post-deployment verification accuracy
5. **Rollback Procedures**: Not covered by this ticket

### Mitigated by Design

1. **Source/Build Mismatch**: Evidence commit verification
2. **Dirty Source**: Working tree check before gate
3. **Stale Evidence**: Commit equality verification at build
4. **Bypass Attempts**: No `-SkipChecks` bypass for quality gate
5. **Mixed-Service Confusion**: Explicit coverage identification

### Accepted Risks

1. **Manual Deployment Path**: User could bypass deploy-smart.ps1 entirely (documented risk)
2. **Evidence Tampering**: User could manually edit evidence files (file system access control)
3. **VPS State**: Cannot verify VPS environment matches expectations (out of scope)
