### 4. Root-Cause Cross-Reference Resolution

**Commands to run:**

```powershell
$register = Import-Csv "audit/Canonical_Root_Cause_Register.csv"
$crosswalk = Import-Csv "audit/Audit_Finding_Root_Cause_Crosswalk.csv"

$registerRCs = $register | Select-Object -ExpandProperty root_cause_id
$crosswalkRCs = $crosswalk | Where-Object { $_.primary_root_cause -ne 'N/A' } | Select-Object -ExpandProperty primary_root_cause -Unique

# Check all crosswalk primary root causes resolve
$unresolved = $crosswalkRCs | Where-Object { $_ -notin $registerRCs }
if ($unresolved) {
    Write-Output "UNRESOLVED: $($unresolved -join ', ')"
} else {
    Write-Output "✓ All primary root causes resolve"
}

# Check related root causes
$related = $crosswalk | Where-Object { $_.related_root_causes -ne '' } | Select-Object -ExpandProperty related_root_causes | ForEach-Object { $_ -split ',' } | ForEach-Object { $_.Trim() } | Where-Object { $_ -ne '' } | Select-Object -Unique

$unresolvedRelated = $related | Where-Object { $_ -notin $registerRCs }
if ($unresolvedRelated) {
    Write-Output "UNRESOLVED RELATED: $($unresolvedRelated -join ', ')"
} else {
    Write-Output "✓ All related root causes resolve"
}
```

**Verify:**
- ✅ All `primary_root_cause` values in crosswalk resolve to register
- ✅ All `related_root_causes` values resolve to register
- ✅ No dangling root-cause references
