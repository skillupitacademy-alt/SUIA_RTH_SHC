## Gap 1: Duplicate/Conflicting --stage Arguments

**Finding**: `--stage=guards --stage=build` executed only guards and returned 0.

**Root Cause**: Orchestrator used `args.find()` which returns first match, silently ignoring duplicates.

**Correction**: Added explicit validation before execution:

```javascript
// Collect all --stage arguments
const stageArgs = args.filter(arg => arg.startsWith('--stage='));

// CRITICAL: Reject duplicate/conflicting --stage arguments
if (stageArgs.length > 1) {
  console.error(`❌ Conflicting stage arguments: ${stageArgs.join(' ')}`);
  console.error(`   Only one --stage argument is allowed`);
  process.exit(255);
}

// Validate malformed arguments
if (!stageName || stageName.trim() === '') {
  console.error(`❌ Malformed stage argument: ${stageArg}`);
  process.exit(255);
}
```
