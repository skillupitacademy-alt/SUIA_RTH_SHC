## SkillUp data: active source and callers

`apps/skillup-web/src/lib/skillup-data.ts` queries people and placement stores. `getSkillupPrograms` returns invented programs on empty query or exception; `getSkillupProgramBySlug` also searches those invented programs. `getSkillupFaculty` returns invented mentors when empty or query fails and manufactures a quality percentage; `getSkillupMyBatch` and `getSkillupBatches` return a named fabricated batch when enrollment is absent. Dashboard, my-batch and batches construct recording URLs from session IDs without an identified recording source. Placement invents profile/interview/match values and derives synthetic match percentages if ranking fails. Other generated labels, current-date fallback, session materials and curriculum require review, not an inference that every label is persisted truth.

Actual routes: `apps/skillup-web/src/app/api/programs/route.ts`, `api/programs/[slug]/route.ts`, `api/faculty/route.ts`, `api/batches/route.ts`, and `api/student/{dashboard,my-batch,placement}/route.ts`. `fetchSkillupApi` is used by `app/programs/page.tsx`, `app/programs/[slug]/page.tsx`, `app/faculty/page.tsx`, `app/batches/page.tsx`, `app/student/page.tsx` and `app/student/my-batch/page.tsx`; `SessionCalendar.tsx` renders the recording field and currently implies every completed session obtains one. `sitemap.ts` and `programs/[slug]/opengraph-image.tsx` directly call data helpers. The placement API is an active route; no page consumer was established by this search.

A separate authority concern requires Sol review: `fetchSkillupApi` catches non-OK responses including authentication/brand denials and directly calls program/faculty database helpers. Those API routes enforce authentication and brand validation. Do not interpret this observation as permission to invent public/private policy or claim exploitation; a correction must preserve selected access policy and static-build compatibility. A FND13 implementation must distinguish no enrollment/no records from service failure, preserve actual persisted rows and avoid manufacturing session links, scores or people. It must trace and update response consumers and test real data helper plus entry points with isolated injected storage; existing route tests mock the helper and cannot establish fallback correctness. None of these observations are a completed correction or live-store evidence.
