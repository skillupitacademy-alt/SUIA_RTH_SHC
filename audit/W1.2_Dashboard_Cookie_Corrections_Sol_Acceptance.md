new execution claim for that API test in this review.

The five synthetic learner-denial tests exercise a standalone test-defined validator,
not a helper used by the live specs. Treat them as illustrative negative controls;
the independent live exact-URL assertions establish the actual browser behavior.

domain. Leading-dot normalization does not independently certify host-only scope; SHC
host-only issuance is a separately inspected source fact. No cookie value is emitted.
Visible labels do not certify real statistics, course/exam authorization, cache privacy
or server-side cross-tenant resource ownership.
