Pure Bearer callers retain appropriate verification without ambient cookie fallback.
  2. Full Exact-Origin Policy: Replaced arbitrary host allowlists with exact scheme, host, and port matching against authoritative server request origin (`req.nextUrl.origin`) and tenant domain bounds. Rejects mismatched scheme (`https` vs `http`), mismatched port, another tenant's origin (`skillup.test` targeting `realtutorialhub`), deceptive substring host spoofing, userinfo, and missing/null origin headers.

  5. Commit-Then-Throw & Presence Failure Attribution:
     - Proved that when `revokeAll` commits store mutations and then throws, `GlobalLogoutService` raises `RevocationStageError`, the route returns HTTP 500 unknown outcome, and committed revocations in the store are preserved.
     - Proved that when `revokeAll` succeeds but `updateLastActive` fails, `PresenceStageError` is raised with tokens confirmed revoked.
  6. Real `AuditService` Absorption: Instantiated real `AuditService` with a throwing database client insert adapter, proving that `GlobalLogoutService` completes successfully with audit error absorption.
  7. Idempotent Retry: Calling logout-all again succeeds, yielding 0 active sessions without mutating foreign tenant rows or restoring revoked tokens.
