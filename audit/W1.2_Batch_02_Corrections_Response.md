- **Source Evidence**:

- **Corrected Rule**:

  - Ambient header selection cannot infer authenticated tenant context without matching cryptographic JWT claims (`oldPayload.brand === brand`).
- **Test Matrix Reference**: `TC-AUTH-03`, `TC-AUTH-05` in REFRESH-05 Section 7.

### R2: Legacy Policy Must Distinguish Absent from Malformed Claims
- **Source Evidence**:
  - The previous draft loosely allowed non-string or malformed claims to enter the legacy fallback.
  - JWT verification in [`packages/auth/src/token.service.ts`](file:///E:/onlinewebsites/quiz-platform/packages/auth/src/token.service.ts) produces payloads where `brand` may be absent or present.
- **Corrected Rule**:
  - Strict type and value gating:
    - **Absent**: `oldPayload.brand === undefined` is the **only** permitted legacy candidate.
    - **Malformed**: `typeof oldPayload.brand !== 'string'`, empty string `""`, or non-canonical values must fail closed immediately with HTTP `401 Unauthorized` (`Invalid refresh token brand`).
    - **Canonical Values**: Strictly limited to `'realtutorialhub'` and `'skillup'`. Value `'shared'` is forbidden in tenant authority.
  - Option B (Progressive Upgrade) is explicitly documented as a **design proposal** awaiting Sol acceptance, requiring verified cryptographic signature, subject match with active session row, unrevoked DB row, and unexpired JWT.
- **Test Matrix Reference**: `TC-AUTH-01`, `TC-AUTH-02`, `TC-AUTH-06` in REFRESH-05 Section 7.
- **Remaining Uncertainty**: Historical volume of active no-brand tokens in production databases is unknown without live DB read access. The 7-day progressive upgrade window applies from deployment time.

### R6: Role Freshness Must Preserve the Authenticated Principal Boundary
- **Source Evidence**:
  - Learner tokens use `aud: 'user'` and are signed with `REFRESH_SECRET` / `JWT_SECRET`.
  - Admin tokens use `aud: 'admin'` and are signed with `REFRESH_ADMIN_SECRET` / `JWT_ADMIN_SECRET`.
- **Corrected Rule**:
  - **No privilege-class escalation**: If a learner is assigned an administrative role in the database, refreshing their learner token updates their roles array but **strictly preserves** `isAdmin: false` and `aud: 'user'`. Administrative access requires explicit re-authentication at `/api/admin/login`.
  - **Demoted Admin Fails Closed**: If an administrator is demoted in the database, refreshing their admin token **fails closed** with HTTP `401 Unauthorized` (`access_denied:insufficient_permissions`). It does not silently downgrade into a learner token across secret keys.
- **Test Matrix Reference**: `TC-LIFE-04`, `TC-LIFE-05` in REFRESH-06 Section 8.
- **Remaining Uncertainty**: None; cryptographic key and audience separation strictly prevent cross-boundary token forging.
