## 2. Implementation Details

### 2.1 Ingress Brand Context Helper (`request-brand.ts`)
- Added `resolveStrictRefreshBrandFromHeaders(headers)`:
  - Missing or blank raw `x-brand` and `x-platform` returns `{ error: 'missing_brand' }`.
  - Disagreeing non-empty `x-brand` and `x-platform` returns `{ error: 'conflicting_brand' }`.
  - Value `'shared'` or non-canonical strings return `{ error: 'invalid_brand' }`.
  - Preserves the legacy `resolveRequestBrandFromHeaders` resolver for all other callers across the system without modification.

### 2.2 Route Handler Ingress Gate (`refresh/route.ts`)
- For tenant user and admin requests (`portalIdentity !== 'infrastructure'`):
  - Calls `resolveStrictRefreshBrandFromHeaders(_req.headers)`.
  - Missing, conflicting, invalid, or `'shared'` brand contexts return an immediate **400 Bad Request** before any auth service or database delegation.
- For infrastructure requests (`portalIdentity === 'infrastructure'`):
  - Preserves existing behavior, delegating via `resolveRequestBrandFromHeaders`.

### 2.3 Scoped Authority & Verification Ordering (`token-refresh.service.ts`)
- **Verification First Principle**:
  - `verifyRefreshToken` is moved to execute **before** any session state writes.
  - If cryptographic signature, expiration, or audience checks fail, an audit log is emitted and an error is thrown immediately. `updateLastUsed` is **never called** for unverified requests (zero state writes).
- **Non-empty Signed Subject & Subject Parity**:
  - Requires non-empty signed `userId` in the verified JWT payload.
  - Enforces strict subject parity: `oldPayload.userId === existingSession.userId`. Prevents foreign owner rotation attacks. Does not substitute `shadowUserId` or fallback to `sub`.
- **Scope Confusion & Class Consistency**:
  - Rejects conflicting claim sets: `tokenType === 'admin'` with `isAdmin === false`, `tokenType === 'user'` with `isAdmin === true`, or presenting user-tier credentials to request admin audience (`aud: 'admin'`).
- **Brand Claim Categorization**:
  - **Strictly Absent (`brand === undefined`)**: Eligible for legacy progressive upgrade when all prerequisites are met (valid signature, exp > now, matching stored session owner, active unrevoked session).
  - **Malformed (explicit `null`, non-string, empty, `'shared'`, unknown)**: Fails closed immediately with HTTP 401 (`Invalid refresh token: malformed brand claim`).
  - **Canonical Parity**: Enforces `oldPayload.brand.toLowerCase() === brand.toLowerCase()`. Mismatched brands fail closed with HTTP 401 (`Invalid refresh token: tenant brand mismatch`).
- **Atomic CAS Rotation Preserved**:
  - `consumeToken` and `createRefreshToken` remain bound in one single database transaction.
