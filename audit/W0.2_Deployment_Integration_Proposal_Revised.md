## Revised Integration Design

### Core Principle: Mandatory Pre-Build Quality Gate

**NO BYPASS**: SkillHubCore Admin quality gate runs ALWAYS before Docker build
**NO NEW FLAGS**: `-SkipChecks` retains original meaning (legacy lint/typecheck only)
**FAIL-CLOSED**: ANY quality gate failure → ABORT before build/upload

### Step 4.5: Mandatory Quality Gate (REVISED)

**Location**: `scripts/deploy-smart.ps1`, between Step 4 and Step 5

```powershell
# Step 4.5: Mandatory SkillHubCore Quality Gate
Write-Host "`nStep 4.5: SkillHubCore Quality Gate (MANDATORY)" -ForegroundColor Cyan

# Determine which services need quality verification
$servicesRequiringQuality = @()
$servicesWithoutQuality = @()

if ($Services -match "skillhubcore-admin") {
    $servicesRequiringQuality += "skillhubcore-admin"
} else {
    Write-Host "  ℹ️  SkillHubCore Admin not in deployment, quality gate skipped" -ForegroundColor Gray
}

# Add other services as quality gates are implemented
# if ($Services -match "gateway") { $servicesWithoutQuality += "gateway" }

if ($servicesRequiringQuality.Count -eq 0) {
    Write-Host "  ℹ️  No services with quality gates in this deployment" -ForegroundColor Gray
} else {
    Write-Host "  Services with quality gates: $($servicesRequiringQuality -join ', ')" -ForegroundColor White

    # CRITICAL: Verify clean working tree before quality check
    Write-Host "  Checking working tree state..." -ForegroundColor Gray
    $gitStatus = & git status --porcelain
    if ($gitStatus) {
        Write-Error "❌ Working tree has uncommitted changes:"
        Write-Error ($gitStatus -join "`n")
        Write-Error "`nQuality gates test committed source, but build would use dirty working tree."
        Write-Error "Commit changes or stash them before deployment."
        exit 255
    }

    $qualityCommit = (git rev-parse HEAD).Trim()
    Write-Host "  Quality gate commit: $qualityCommit" -ForegroundColor Gray

    # Run quality gate for each service
    foreach ($service in $servicesRequiringQuality) {
        Write-Host "`n  Running quality gate: $service" -ForegroundColor Cyan

        switch ($service) {
            "skillhubcore-admin" {
                & pnpm quality:skillhubcore 2>&1 | Tee-Object -FilePath "logs/quality-gate-$service-$(Get-Date -Format 'yyyyMMdd-HHmmss').log"

                if ($LASTEXITCODE -ne 0) {
                    Write-Error "`n❌ Quality gate FAILED for $service (exit $LASTEXITCODE)"
                    Write-Error "   1=architecture, 2=security, 3=lint, 4=typecheck, 5=test, 6=build"
                    Write-Error "`n   See logs/quality-gate-$service-*.log for details"
                    Write-Error "`n   Deployment ABORTED before Docker build."
                    exit $LASTEXITCODE
                }

                Write-Host "  ✅ Quality gate PASSED: $service" -ForegroundColor Green
            }
            # Future services...
        }
    }

    # Record quality evidence
    $script:QualityEvidence = @{
        timestamp = (Get-Date -Format "yyyy-MM-ddTHH:mm:ssZ")
        commit = $qualityCommit
        workingTreeClean = $true
        servicesCovered = $servicesRequiringQuality
        servicesUncovered = $servicesWithoutQuality
        allGatesPassed = $true
    }

    Write-Host "`n  ✅ All mandatory quality gates PASSED" -ForegroundColor Green
}

# CRITICAL: Verify commit hasn't changed between quality check and build
Write-Host "`n  Verifying source stability..." -ForegroundColor Gray
$currentCommit = (git rev-parse HEAD).Trim()
if ($qualityCommit -and ($currentCommit -ne $qualityCommit)) {
    Write-Error "❌ Source changed after quality check!"
    Write-Error "   Quality tested: $qualityCommit"
    Write-Error "   Current HEAD:   $currentCommit"
    Write-Error "`n   Re-run deployment to test current source."
    exit 255
}

# Verify working tree still clean
$gitStatus = & git status --porcelain
if ($gitStatus) {
    Write-Error "❌ Working tree changed after quality check!"
    Write-Error "   Quality tested clean commit, but working tree now dirty."
    Write-Error "   Commit changes or stash them."
    exit 255
}

Write-Host "  ✅ Source stable: $currentCommit (clean)" -ForegroundColor Green
```

### Key Design Points

#### 1. No `-SkipChecks` Bypass

**OLD (REJECTED)**:
```powershell
if (-not $SkipChecks) {
    & pnpm quality:skillhubcore
}
```

**NEW (REQUIRED)**:
```powershell
# Step 4.5 ALWAYS runs for SHC services
# -SkipChecks only affects legacy Steps 3-4 (redundant lint/typecheck)
```

**Rationale**: Quality gate is MANDATORY for services that have it. No bypass.

#### 2. Working-Tree Drift Detection

**Check BEFORE quality gate**:
```powershell
$gitStatus = & git status --porcelain
if ($gitStatus) {
    Write-Error "Working tree has uncommitted changes"
    exit 255
}
```

**Check AFTER quality gate, BEFORE build**:
```powershell
if ($ currentCommit -ne $qualityCommit) {
    Write-Error "Source changed after quality check"
    exit 255
}
```

**Rationale**: Quality evidence binds to EXACT tested commit + clean tree

#### 3. Per-Service Coverage Clarity

**Evidence Structure**:
```json
{
  "servicesCovered": ["skillhubcore-admin"],
  "servicesUncovered": ["gateway", "api-server"],
  "allGatesPassed": true
}
```

**NOT**:
```json
{
  "gatesPassed": true  // Ambiguous! Which services?
}
```

**Rationale**: Mixed deployments must state EXACTLY which services were quality-checked

#### 4. Fail-Closed Build Prevention

**ANY gate failure**:
```powershell
if ($LASTEXITCODE -ne 0) {
    Write-Error "Deployment ABORTED before Docker build."
    exit $LASTEXITCODE
}
```

**Rationale**: Failed quality gate = no build, no upload, no deployment

### Manifest Enhancement

**In `build-save-images.ps1`**, merge quality evidence:

```powershell
$manifest = @{
    buildTimestamp = (Get-Date -Format "yyyy-MM-ddTHH:mm:ssZ")
    gitCommit = (git rev-parse HEAD).Trim()
    services = $services
    quality = if ($script:QualityEvidence) {
        $script:QualityEvidence
    } else {
        @{
            servicesCovered = @()
            servicesUncovered = $services
            allGatesPassed = $false
            reason = "No services with quality gates in this deployment"
        }
    }
}

$manifest | ConvertTo-Json -Depth 10 | Set-Content "manifest.json"
```

### `-SkipChecks` Behavior (UNCHANGED)

**What `-SkipChecks` DOES skip**:
- Step 3: ESLint (redundant with quality gate lint)
- Step 4: TypeScript check (redundant with quality gate typecheck)

**What `-SkipChecks` DOES NOT skip**:
- Step 4.5: Mandatory quality gate (NEW, ALWAYS runs for applicable services)

**Rationale**: Legacy flag retains original purpose (skip redundant checks), does NOT bypass new mandatory gate

**No New Flags**: Do NOT add `-SkipQualityGate`, `-Force`, `-Emergency`, etc.

---

### Mixed-Service Handling

**Scenario**: Deploying `skillhubcore-admin` + `gateway`

**Evidence**:
```json
{
  "servicesCovered": ["skillhubcore-admin"],
  "servicesUncovered": ["gateway"],
  "allGatesPassed": true
}
```

**Interpretation**:
- ✅ SkillHubCore Admin: Quality verified
- ⚠️ Gateway: NO quality verification (gate not implemented yet)
- ℹ️ Deployment proceeds (covered service passed, uncovered service has no gate yet)

**Future State** (when gateway gets quality gate):
```json
{
  "servicesCovered": ["skillhubcore-admin", "gateway"],
  "servicesUncovered": [],
  "allGatesPassed": true
}
```

### Failure Scenarios

#### Scenario 1: Quality Gate Fails

```
Step 4.5: SkillHubCore Quality Gate (MANDATORY)
  Running quality gate: skillhubcore-admin
  ...
  ❌ Quality gate FAILED for skillhubcore-admin (exit 4)
     4=typecheck

  See logs/quality-gate-skillhubcore-admin-*.log for details

  Deployment ABORTED before Docker build.

Exit: 4
```

**Result**: No Docker build, no images created, no upload, previous deployment unchanged

#### Scenario 2: Working-Tree Drift

```
Step 4.5: SkillHubCore Quality Gate (MANDATORY)
  Checking working tree state...
  ❌ Working tree has uncommitted changes:
   M apps/skillhubcore-admin/src/app/api/health/route.ts

  Quality gates test committed source, but build would use dirty working tree.
  Commit changes or stash them before deployment.

Exit: 255
```

**Result**: Deployment aborted before quality check, developer must commit/stash

#### Scenario 3: Commit Changed After Quality Check

```
Step 4.5: SkillHubCore Quality Gate (MANDATORY)
  Quality gate commit: d0a9d49f
  ...
  ✅ All mandatory quality gates PASSED

  Verifying source stability...
  ❌ Source changed after quality check!
     Quality tested: d0a9d49f
     Current HEAD:   e1b2c3d4

  Re-run deployment to test current source.

Exit: 255
```

**Result**: Deployment aborted before build (someone pushed/committed during deployment)
