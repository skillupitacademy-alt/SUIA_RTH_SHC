## Source and offline causal evidence

SUIA's logout BFF discards upstream Set-Cookie headers and manually expires accessToken,
refreshToken and csrfToken without Domain. The shared proxy already rewrites upstream
cookie domains for the actual request host. Its login response can establish domain
cookies, which the BFF's replacement expiry fails to remove.

An independent headless Chromium experiment used only synthetic cookie values and
intercepted local responses; no application or database request was dispatched. Each
fresh context established an HttpOnly domain cookie for skillup.localhost, Path=/:

| Expiry response | Present before | Present afterward |
| --- | --- | --- |
| Current host-only, Secure, SameSite=None | true | true |
| Matching Domain, Secure, SameSite=None | true | false |
| Host-only, no Secure, SameSite=Lax | true | true |

Only boolean results were printed; no cookies were exported. This supports the domain
mismatch independently of a general claim about Secure cookies on local HTTP. It does
not certify every deployed hostname or all legacy cookie variants.

RTH's logout BFF has the same source pattern. No RTH live journey was run in this review;
do not promote that observation to an independently reproduced RTH runtime result.
