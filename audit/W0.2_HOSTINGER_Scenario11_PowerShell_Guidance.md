## Verified mechanism

The assertion that a function cannot be visible to `& script.ps1` is incorrect.
A global function in the same child PowerShell process is visible. However,
module auto-loading can replace the function: the first module-qualified call
to Microsoft.PowerShell.Utility\Get-FileHash imports the module's exported
Get-FileHash command. Explicitly import the module BEFORE defining the override.

Sol reproduced a missing-injection result without that import, then tested
the corrected version with powershell -NoProfile -ExecutionPolicy Bypass -File.
A disposable wrapper called a builder script followed by deploy-smart.ps1;
both hashed the same fixture tar. The override delegated both calls correctly
and recorded exactly ONE injection, only from deploy-smart.ps1. Terminal result:

## Child wrapper pattern for Sonnet to integrate

Write a literal child wrapper file rather than interpolating a large -Command
string. Pass absolute fixture paths using parameters. The following belongs
inside that child wrapper; it must run in the SAME process as the deployer.

```powershell
param(
    [string]$DeployScript,
    [string]$FixtureRepo,
    [string]$TracePath
)
$ErrorActionPreference = 'Stop'
Import-Module Microsoft.PowerShell.Utility -ErrorAction Stop
$global:ShcDriftRepo = $FixtureRepo
$global:ShcDriftTrace = $TracePath
$global:ShcExpectedDeployer = [IO.Path]::GetFullPath($DeployScript)
$global:ShcDriftInjected = $false

function global:Get-FileHash {
    [CmdletBinding()]
    param([string[]]$LiteralPath, [string]$Algorithm = 'SHA256')

    $hash = Microsoft.PowerShell.Utility\Get-FileHash @PSBoundParameters
    $caller = (Get-PSCallStack)[1].ScriptName
    if ($caller -and
        [IO.Path]::GetFullPath($caller) -eq $global:ShcExpectedDeployer -and
        $LiteralPath.Count -eq 1 -and
        $LiteralPath[0] -like '*.tar' -and
        -not $global:ShcDriftInjected) {
        Set-Content -LiteralPath (Join-Path $global:ShcDriftRepo 'drift-at-final-check.txt') -Value 'test drift'
        Set-Content -LiteralPath $global:ShcDriftTrace -Value $caller
        $global:ShcDriftInjected = $true
    }
    $hash
}

Set-Location -LiteralPath $FixtureRepo
try {
    & $DeployScript -Services 'skillhubcore-admin' -NonInteractive
    exit $LASTEXITCODE
} catch {
    Write-Output ($_ | Out-String)
    exit 1
}
```

All current Get-FileHash calls in the real pipeline use LiteralPath/Algorithm.
The wrapper may broaden parameter support if a demonstrated call requires it.
Output from the delegated hash must remain unchanged; write traces to files.
The globals live only in the disposable child, which exits after deployment.
