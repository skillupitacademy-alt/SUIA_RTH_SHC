## Why this task is next

The existing DELETE /api/auth/sessions/[sessionId] route supplies the verified
brand-local user ID to GlobalLogoutService. That service drops it when calling
TokenRepository.revokeById; the repository owner argument is optional. Fix the
authoritative persistence boundary rather than adding a parallel route or a
read-before-write authorization check vulnerable to race conditions.
