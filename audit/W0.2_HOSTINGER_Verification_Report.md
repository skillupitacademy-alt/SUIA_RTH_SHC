### Context & Gap Addressed
In review `434b3556`, Sol confirmed that the production deployment pipeline code is fully sound and that negative test scenarios 4, 6, 7, 9, and 10 all execute properly with zero-upload and explicit rejection assertions. However, Sol noted that in commit `434b3556`, Scenario 11's drift was triggered synchronously during Docker save, which caused the builder's post-packaging check to reject prior to manifest creation, duplicating Scenario 9 rather than testing the deployer's Step 6 pre-upload check.

Sol established that:
1. Scenario 11 must inject source drift **after the builder returns**, synchronously when the deployer hashes the release archive `.tar` in Step 6.
2. In PowerShell, module auto-loading can replace a `Get-FileHash` global override; therefore, `Import-Module Microsoft.PowerShell.Utility -ErrorAction Stop` must precede the function override.
3. Sensitivity must be proven by a **mutation test**: removing the final source check block in a disposable copy must cause Scenario 11 to fail (deployment succeeds, mocked SCP reached).

Both the normal run and the disposable mutation run have been independently executed and verified by Gemini.

## 2. Technical Implementation: Sol's Pre-Import Pattern

In commit `44e308a1`, Claude implemented Sol's exact child wrapper pattern in [`scripts/__tests__/inject-drift-at-deployer-hash.ps1`](file:///E:/onlinewebsites/quiz-platform/scripts/__tests__/inject-drift-at-deployer-hash.ps1):

1. **Pre-Importing Utility Module**:
   ```powershell
   Import-Module Microsoft.PowerShell.Utility -ErrorAction Stop
   ```
   This prevents module auto-loading from overwriting the global override when `Get-FileHash` is called.
2. **Selective Interception via Callstack**:
   The override verifies the calling script is `deploy-smart.ps1` (not the builder), the argument is a single `.tar` file, and injection has not yet occurred.
3. **Synchronous Injection & Tracing**:
   Writes `drift-at-final-check.txt` directly into the fixture repository and records the caller script path to `$global:ShcDriftTrace`.
4. **Isolated Execution**:
   Executes `& $DeployScript -Services 'skillhubcore-admin' -NonInteractive` in the child process, propagating exit codes accurately.
