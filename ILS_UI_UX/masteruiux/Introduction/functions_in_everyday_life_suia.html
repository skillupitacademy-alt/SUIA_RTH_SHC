Functions in Everyday Life

Let's explore a real-world situation to see why functions are needed and how they help us build better JavaScript programs.

Real Problems
Real Solutions
Real Skills!

Learning Goal

Understand how real-world programming problems lead to the need for functions, and see how functions provide a clean and reusable solution.

1

Real-World Situation

You are building an e-commerce website. Customers add products to their cart, and the website needs to calculate the total price frequently.

The total needs to be calculated every time products are added or removed.

2

The Requirement (Need)

We need a way to calculate the total price from a list of product prices. This calculation will be used many times in different parts of the application.

3

The Solution: Functions

We create a function that takes a list of prices, calculates the total, and returns the result. Now we can use this function whenever we need to calculate a total.

function calculateTotal(prices) {
  let total = 0;
  for (const price of prices) {
    total += price;
  }
  return total;
}
4

Where Is It Used?

The same function can be used in many places across the application.

Key Takeaway

Functions are created because real-world applications often need to perform the same task multiple times. They help us write cleaner, more organized, and maintainable code.
