What is a Function?

A function is a reusable block of code designed to perform a specific task. You can give it a name, pass input values (parameters), and it can return a result after executing the code inside it.

Real-World Example

An e-commerce website needs to calculate the total price of items in a shopping cart.

Instead of writing the calculation code multiple times, we can use a function to calculate the total.

function calculateTotal(prices) {
  let total = 0;
  for (const price of prices) {
    total += price;
  }
  return total;
}

const items = [799, 199, 49, 89];
console.log(calculateTotal(items)); // Output: 1136
