## Purpose

This matrix consolidates the complete 18-family educational reference corpus review into one authoritative knowledge structure.

It distinguishes:

```
VERIFIED REFERENCE_VERSION
        ≠
DECLARED_VERSION (incomplete/partial)
        ≠
PROPOSED_VERSION (historical/not evidenced)
        ≠
NOT VERIFIED
```

**Critical Principle:**

```
Educational Reference Corpus (this matrix)
        ≠
Production Implementation Status
        ≠
Runtime Authority (UBRC/ILS/LSNB/RSSB)
```

The production/runtime correlation is **Stage 5 — Architecture Audit**, conducted separately after the educational truth is frozen.

---

## Evidence Classification Legend

| Classification | Meaning |
|---|---|
| **VERIFIED** | Full specification exists in converted `.md` corpus |
| **DECLARED/INCOMPLETE** | Version mentioned but specification incomplete |
| **PARTIAL** | Specification exists but acknowledged as partial |
| **NOT EVIDENCED** | No specification found in source file |
| **EXPLICITLY EXCLUDED** | Source explicitly states this is not included |
| **FINAL** | Source explicitly closes family at this version |
