The Solution: Functions

We create a function that takes a list of prices, calculates the total, and returns the result. Now we can use this function whenever we need to calculate a total.

JavaScript 
function calculateTotal(prices) {
  let total = 0;
  for (const price of prices) {
    total += price;
  }
  return total;
}
