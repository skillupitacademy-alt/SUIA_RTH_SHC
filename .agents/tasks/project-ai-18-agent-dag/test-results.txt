6. ROOT CAUSE ANALYSIS
===========================================

Issue 1: Agent Count Mismatch
- Design documents reference "15 agents" (FEAT-001)
- DAG implementation has 24 agents (10 certification gates as separate nodes)
- Agent registry has 28 agent types (additional runtime_agent, playwright_browser_agent, etc.)
- Tests are hardcoded to expect 23 agents (pre-expansion count)

Issue 2: DAG vs Registry Misalignment
- DAG has 24 agent IDs (agent-01, agent-02, ... agent-12a-12j, agent-13, 14, 15)
- Registry has 28 AgentType enums (different naming: gate_controller, repository_auditor, etc.)
- No clear 1:1 mapping between DAG agent IDs and Registry agent types
- DAG uses kebab-case IDs (agent-01-repository-auditor)
- Registry uses snake_case enum values (repository_auditor)

Issue 3: Missing Gate Implementations
- Certification gates are defined in DAG but tests indicate implementations are incomplete
- Gate execution logic may not be properly integrated with the agent coordinator
