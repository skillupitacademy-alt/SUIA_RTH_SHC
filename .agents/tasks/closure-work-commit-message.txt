chore: Closure Work - Progress Isolation, Worker Improvements & Cache Enhancements

EXECUTIVE SUMMARY

This closure work addresses critical quality improvements across tutorial progress 
tenant isolation, worker lease management, service worker caching strategies, and 
comprehensive test coverage expansion. The changes implement tenant-scoped tutorial 
progress isolation to support independent dual-brand progress tracking, enhance worker 
lease concurrency handling with strengthened ownership transitions, and apply stricter 
private caching policies to user-specific progress responses. Configuration updates 
across Next.js applications address Sentry release automation, next-intl CommonJS 
dependency tracing, and build-time environment constraints.

The tutorial progress repository now enforces mandatory tenant context (realtutorialhub, 
skillup, skillhubcore) on all read and write operations, preventing cross-tenant data 
leakage through explicit tenant predicates in WHERE clauses and database-level write 
locks keyed by tenant/user/subtopic tuples. Worker lease management received type safety 
improvements and refined error handling for outbox repository resolution and transactional 
intent enrollment. Service worker tests expanded to validate private navigation caching 
policies and offline fallback behavior across both RTH and SUIA applications.

Test coverage improvements include 23 tutorial progress tests with explicit tenant context, 
stronger assertions for tenant isolation predicates, and corrections to stale test fixtures 
expecting outdated brand/payload shapes. API server export status tests now include brand 
context in job payloads and user verification responses. Worker tests received comprehensive 
type annotations removing unsafe `any` usage across outbox recovery, badge award, and 
certificate issuance probes. SUIA placement tests validate truth control boundaries including 
database failure propagation, vector service fallback, and uncalibrated matching status.

Next.js configuration updates include replacing next-intl ESM plugin entry with CommonJS 
require() to support webpack Node dependency tracing, conditional Sentry release automation 
gated by SENTRY_AUTH_TOKEN presence, and isolated worker CPU constraints for LLM execution 
environments. Docker context exclusions expanded to cover Python virtual environments, 
Playwright artifacts, graphify output, and additional evidence directories. Evidence 
handoff documentation received continuation updates documenting completed work boundaries 
and remaining verification gates.

This commit does not include database migration execution, Docker deployment, or canonical 
acceptance ledger updates. The implemented tenant isolation pattern prepares for future 
DDL alignment requiring tenant_id column addition, tenant/user/subtopic unique constraint, 
and provenance-verified data backfill. All production builds, typechecks, and targeted 
test suites pass with documented boundaries.
