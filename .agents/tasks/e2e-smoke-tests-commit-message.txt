ARCHITECTURAL OVERVIEW
=============================================

Multi-Tenant Content Delivery Architecture
-------------------------------------------
The tested architecture implements a hub-and-spoke model where:

1. **SHC Admin (Content Hub)** - Single administrative portal at skillhubcore.localhost:3007 where authorized admins author tutorial content using:
   - Tutorial Page Content Builder - 18-block composable content editor for tutorial pages
   - Tutorial Left Sidebar Builder - Hierarchical navigation tree editor
   - Shared content repository in MainDB and TutorialDB (Remote Neon PostgreSQL)

2. **SUIA & RTH (Consumption Spokes)** - Multiple branded learner portals consuming shared content:
   - SUIA at skillup.localhost:3009 (SkillUp IT Academy branding)
   - RTH at realtutorialhub.localhost:3003 (Real Tutorial Hub branding)
   - Each portal fetches tutorial content via tutorialDeliveryService resolvers
   - Brand-specific overrides take precedence over shared content (skillup > shared, realtutorialhub > shared)
   - Complete tenant isolation (SUIA learners cannot access RTH content and vice versa)

3. **Content Flow Pipeline**:
   SHC Admin Authors Content → Publishes to TutorialDB → tutorialDeliveryService Resolvers → Brand-Specific Rendering → Learner Portals

Smoke Test Strategy
-------------------
The E2E smoke tests validate critical success paths through the multi-tenant architecture:

- **Headless Chromium Execution**: Tests run in Playwright's headless browser for CI/CD compatibility
- **Evidence Collection**: Full-page screenshots at every critical step for visual regression baseline
- **HTTP Status Validation**: Confirms 200 OK responses for all authenticated routes
- **Multi-Tenant Isolation**: Separate authentication flows and distinct credentials per portal
- **Content Sharing Verification**: Same tutorial paths (programming/java/java-basics/whatisjava/*) on different portals
- **Brand Rendering Validation**: Visual evidence of distinct branding on SUIA vs RTH portals

Test Infrastructure
------------------
- **Test Framework**: Playwright with TypeScript
- **Viewport**: 1440x900 desktop resolution (consistent baseline)
- **Timeout Handling**: Extended timeouts (5 minutes) for Next.js Turbopack JIT warmup
- **Database**: Remote Neon PostgreSQL (production-like environment, not mocked data)
- **Evidence Storage**: .evidence/screenshots/ directory with timestamped and task-prefixed filenames

MULTI-TENANT VALIDATION
=============================================

Architecture Validated
----------------------
**SHC Admin (Content Hub) → SUIA/RTH (Consumption Spokes)**

The E2E tests prove the complete multi-tenant content delivery pipeline:

1. **Shared Content Authoring**
   - SHC Admin authors tutorial content once in Tutorial Page Content Builder
   - Content stored in TutorialDB with brand=shared (default)
   - Sidebar navigation authored once in Tutorial Left Sidebar Builder
   - Hierarchy synchronized from MainDB to TutorialDB (ensureTopicHierarchySynced)

2. **Brand-Specific Content Delivery**
   - tutorialDeliveryService.getTutorialByPage(brand, domain, subject, topic, subtopic, page)
   - Resolver checks brand-specific override first: `WHERE brand = 'skillup' AND ...`
   - Falls back to shared content if no override: `WHERE brand = 'shared' AND ...`
   - Returns null if no published content found (draft gating)

3. **Multi-Tenant Isolation Verified**
   - **Different Credentials**: SUIA uses student@skillupitacademy.com, RTH uses ajayshah@gmail.com
   - **Different Domains**: skillup.localhost:3009 vs realtutorialhub.localhost:3003
   - **Separate Sessions**: Independent browser contexts prevent session leakage
   - **Tenant-Specific Data**: Each tenant has own user accounts, progress tracking, subscriptions

4. **Content Sharing Across Tenants**
   - Same tutorial path on both portals: /tutorial-v2/programming/java/java-basics/whatisjava/what-is-java
   - Proves shared content (brand='shared') successfully delivered to both SUIA and RTH
   - Content identical (same blocks, same text, same structure)
   - Only branding differs (header logo, color scheme, domain)

5. **Brand Override Precedence**
   - If SHC Admin authors content with brand='skillup', only SUIA sees it
   - If SHC Admin authors content with brand='realtutorialhub', only RTH sees it
   - If SHC Admin authors content with brand='shared', both portals see it
   - Brand-specific content takes precedence over shared (resolver query order)
