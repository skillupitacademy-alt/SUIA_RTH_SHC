# 📘 PRD: RealTutorialHub Landing Page (Figma Design)

---

## 🧠 1. Product Vision

RealTutorialHub is **NOT just an LMS**.

It is an **Adaptive Learning Engine** where:

* Students **learn → practice → get AI help → build projects → fix weak areas**
* Entire system is powered by:

  * Tutorial Engine (6 blocks learning)
  * Assignment Engine (difficulty-based practice)
  * AI Tutor (context-aware help)
  * Remediation Engine (personalized recovery)

👉 As defined in architecture:

* Learning is structured into **6 content blocks per subtopic** 
* AI Tutor gives contextual help using subtopic content 
* Weak areas automatically trigger remediation plans
