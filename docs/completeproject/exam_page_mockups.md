# Exam Page Visual Mockups

I have designed the **Exam Page** for both brands, focusing on a premium, functional, and "Zero-Gradient" aesthetic that aligns with our current landing page and gateway designs.

## Design Philosophy
- **Zero-Gradient Core**: Using solid primary colors (`#d03f00` for RTH and Royal Blue for SkillUp) to create a professional, high-distraction-free testing environment.
- **Card-Based UI**: The question console is housed in a high-contrast white card for maximum readability.
- **HUD Intelligence**: Spatial normalization for the timer, progress grid, and navigation controls.

### **Key Layout Elements:**
1.  **Top Bar**: Persists the Timer, Breadcrumbs (Subject > Topic), and Logo.
2.  **Central Console**: Large, accessible typography for the Question Text and Radio-based Options.
3.  **Right Sidebar**: A navigatable grid of question numbers showing status (Attempted, Flagged, Pending).
4.  **Footer Action Zone**: Large primary-colored action buttons (Previous, Flag for Review, Save & Next).
