# Phase 8: Automated Learning Journeys (Upstash Workflow)

## Objective
Transition from reactive tests to proactive multi-day learning journeys.

## Key Features
1. **Durable Follow-ups**: Automated study notes 48h after exam completion.
2. **Retention Workflows**: 7-day re-test cycles for core concepts.
3. **Adaptive Branching**: Dynamic adjustment of study paths based on performance.

## Tech Stack
- **Upstash Workflow**: Durable execution for long-running processes.
