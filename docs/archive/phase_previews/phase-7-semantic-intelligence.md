# Phase 7: Semantic Intelligence (Upstash Vector)

## Objective
Enable the platform to understand the *meaning* of content.

## Key Features
1. **Semantic Search**: Natural language practice discovery.
2. **Duplicate Detection**: Identifying conceptually identical questions.
3. **Smart Recommendations**: Gap-filling practice based on semantic distance.

## Tech Stack
- **Upstash Vector**: Serverless vector database.
- **OpenAI Embeddings**: `text-embedding-3-small` (1536d).
