## ACTUAL TUTORIAL V2 REQUEST FLOW

### Page Load
```text
Browser navigates to:
/tutorial-v2/[domain]/[subject]/[topic]/[subtopic]/[navigationNodeId]

Example:
/tutorial-v2/full-stack-development/backend-development/java/what-is-java-12efacf1/whatisjava
```

### Server-Side Rendering (Next.js)
```text
1. Next.js RSC page.tsx executes
   ↓
2. Read accessToken from cookies
   ↓
3. If no token → redirect to /login?redirect={currentPath}
   ↓
4. Extract learnerId from middleware headers (x-user-id)
   ↓
5. Call resolveRuntimeContext()
   ↓
6. resolveRuntimeContext() calls getPublishedTutorialPagePayload()
   ↓
7. Tutorial hierarchy + sidebar data retrieved
   ↓
8. Render <TutorialPageShell> with payload
```

### Backend API Calls (Server-Side)

The Tutorial V2 page does **NOT** make client-side API calls for sections/progress during initial render.

Instead, it uses **server-side data fetching**:

```text
resolveRuntimeContext()
  ↓
getPublishedTutorialPagePayload()
  ↓
Imports from tutorialSidebarDelivery.ts
  ↓
Queries database directly OR calls internal API
  ↓
Returns TutorialPagePayload (sidebar + hierarchy)
```

**Key Architecture Point**:
- Tutorial V2 uses **Server Components** (RSC)
- Data is fetched **server-side** during page render
- No `/api/tutorial/sections` or `/api/tutorial/progress` calls from browser
- The BFF **directly queries the database** or uses INTERNAL_API_URL

  ↓

  ↓

Tutorial V2 uses **server-side data fetching**, not client-side API calls.

## PREVIOUS 403 EXPLANATION

### Test Approach Used
```text
1. Login via api.realtutorialhub.com/api/auth/login
2. Receive cookie for domain: .realtutorialhub.com (assumed)
3. Try to access user.realtutorialhub.com/api/tutorial/sections
4. Result: 403 Forbidden
```

### Why 403 Occurred

**Root Cause**: Cookie domain mismatch + route authentication

1. **Cookie Scope Issue**:
   - Login through `api.realtutorialhub.com` may set cookie for `.realtutorialhub.com`
   - But BFF authentication may validate the cookie differently
   - Cross-subdomain cookie handling may be restricted

2. **Route Not Configured**:
   - `/api/tutorial/sections` and `/api/tutorial/progress` may not be valid BFF routes
   - Gateway routing table shows `/tutorial` routes to `TUTORIAL_SERVICE_URL` with `auth: true`
   - But these specific endpoints may not exist or may require different auth

3. **Wrong Authentication Context**:
   - Test used API gateway auth (JWT in response body)
   - Tutorial V2 page uses BFF auth (cookie-based session)
   - These are different authentication contexts

### Exact Source of 403
**Most Likely**: BFF route handler or middleware

```text
user.realtutorialhub.com/api/tutorial/sections
  ↓
BFF Next.js API route
  ↓
Authentication middleware validates accessToken cookie
  ↓
Cookie not recognized / not present / wrong format
  ↓
403 Forbidden
```
