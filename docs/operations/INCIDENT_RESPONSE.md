# Incident Response

Severity levels
- SEV1: Platform down or data loss.
- SEV2: Major feature outage or high error rate.
- SEV3: Partial degradation.

On-call steps
1) Acknowledge alert and assess impact.
2) Identify failing services and recent deploys.
3) Roll back if necessary.
4) Scale infrastructure if saturation.
5) Communicate status and ETA.

Post-incident
- Write postmortem within 48 hours.
- Track action items in backlog.
