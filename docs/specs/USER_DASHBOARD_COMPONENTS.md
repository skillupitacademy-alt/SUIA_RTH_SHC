# 🧩 User Dashboard Components (Figma Input)

The following core components represent the constituent elements of the User Dashboard, identified for the Figma design process.

## 1. Welcome & Primary Actions
*   **Greeting Title**: Personalized "Welcome back, [Name]!" header.
*   **Sub-Header Description**: Brief motivational text.
*   **Primary CTA (Adaptive)**: "Start Adaptive Mission" button (includes pulse icon).
*   **Secondary CTA (Manual)**: "Start New Exam" button.

## 2. Stats & Analytics Grid (4-Card Group)
*   **Exams Taken Card**: Total count + trend indicator.
*   **Average Score Card**: Accuracy percentage + trend delta + info/tooltip trigger.
*   **Mastery Points Card**: Cumulative points tracker + info/tooltip trigger.
*   **Global Rank Card**: User's platform rank (with "Top X%" badge and unlock-logic label).

## 3. Smart Tutor Insights Panel
*   **Panel Header**: Brain icon, "Smart Tutor Insights" title, and "Number of Focus Areas" badge.
*   **Notification/Inbox Bell**: Navigation link with unread count badge.
*   **Topic Insight Item (Expandable Card)**:
    *   **Level Badge**: "Revise / Practice / Advance" status.
    *   **Accuracy Gauge**: Progress bar + percentage.
    *   **Explainability Trigger**: "Why?" button.
    *   **Detail Section**: "Reason for Recommendation" box, "Weak Subareas" chip-list, and "Topic Progress Chart".
    *   **Study Actions**: "View Study Notes" button and "Open Study Guide" link.
    *   **Live Help CTA**: "Request Live Help" button with status-tracking (Processing/Sent).

## 4. Activity Tracking List
*   **Section Title**: "Recent Activity" header.
*   **Activity Row**:
    *   **Status Badge**: "Completed / In-Progress".
    *   **Content**: Exam Title, Score (if applicable), and Relative Time (e.g., "2h ago").
    *   **Primary Action**: Link to Report or Resume Exam.
*   **Footer Link**: "View All Quizzes" button.

## 5. Navigation & Identity
*   **Sidebar (Desktop)**: Logo, Navigation links (Dashboard, Exams, Reports), and User Profile/Logout trigger.
*   **Mobile Navigation Bar**: Quick-access touch icons for core app sections.
*   **User Avatar**: Circular profile image/placeholder in Header/Sidebar.
