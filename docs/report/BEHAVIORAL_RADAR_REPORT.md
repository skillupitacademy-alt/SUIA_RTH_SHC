# Report: Behavioral & Cognitive Radar

## 🎯 Objective
To visualize the candidate's professional "DNA" using the three primary skill dimensions.

## 📊 Dimension Mapping
- **Primary Source**: `results_by_dimension`
- **Dimension Type**: `category`
- **Categories**: `technical`, `cognitive`, `process`

---

## 📈 Analysis Views

### 1. The Radar (Spider) Chart
A 3-point radar graph showing the balance between different competency types.

- **Technical**: Pure coding and systems knowledge.
- **Cognitive**: Logic, problem-solving, and architectural thinking.
- **Process**: Documentation, testing standards, and SDLC compliance.

### 2. Category Distribution
- **High Technical / Low Process**: Needs an environment with established pipelines.
- **High Cognitive / High Process**: Potential for Leadership/Architect roles.

---

## 📝 Business Insight
"Candidate is a 'Pure Problem Solver' (High Cognitive), excelling at logic but currently low on 'Process' compliance (Testing/Docs)."
