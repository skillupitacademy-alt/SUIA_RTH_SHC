Why Do We Need Functions?

Let's start with a common problem, understand the need for a solution, and then see how functions in JavaScript help us solve it.

Learn
Apply
Grow
Can we write the same code again and again?
?

Learning Goal

Understand why functions are needed in JavaScript by looking at a real problem and how functions provide a clean and reusable solution.

1

The Problem

Imagine you are building a simple calculator. You need to add two numbers many times in your program.

Without a Function
let result1 = 5 + 3;
// 8
let result2 = 10 + 4;
// 14
let result3 = 25 + 7;
// 32
let result4 = 100 + 50;
// 150
!

What's the problem?

  • We are writing the same code again and again.
  • It makes the program longer.
  • It is harder to maintain.
  • If we need to change the logic, we must update every place where it appears.
2

The Need

We need a reusable way to perform the same task multiple times.

3

The Solution: Functions

A function allows us to group a set of statements together, give it a name, and use it whenever needed.

Using a Function
1
function add(a, b) {
2
return a + b;
3
}
4
 
5
console.log(add(5, 3)); // 8
6
console.log(add(10, 4)); // 14

How It Works

1
Define the function
We write the logic once inside a function.
2
Provide input (arguments)
We pass values when we call the function.
3
Get the output (return value)
The function performs the task and returns a result.

Key Takeaway

Functions help us avoid repeating the same code. They make our JavaScript programs cleaner, more organized, and easier to maintain.
